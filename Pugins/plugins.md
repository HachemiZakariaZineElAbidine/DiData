# DiData Components

Vue.js + Vuetify-based UI component library. Full docs: https://test.swissdidata.com/test/docs/didata-components/

---

## Form & Data Entry

| Component | Description |
|---|---|
| `EntitiesCreatorForm` | Form for creating new entities |
| `EntityUpdateForm` | Form for updating existing entities |
| `FormEditor` | Generic form builder/editor |
| `DidataTextField` | Text input field |
| `DidataTextarea` | Multi-line text input |
| `DidataCombobox` | Combobox input (combo of text + select) |
| `DidataSelect` | Dropdown select field |
| `DidataFieldsSelect` | Select component for choosing fields |
| `ForeignFieldSelect` | Select for foreign key / related entity fields |
| `SwitchField` | Switch toggle used inside forms |
| `DidataSwitch` | Standalone switch/toggle component |
| `DidataFileField` | File upload input field |
| `RequiredRedStartLabel` | Label with red asterisk for required fields |

---
