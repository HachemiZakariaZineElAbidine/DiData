# Actions

*Par Sabrina Gac*

It permits the creation of different actions to be performed on any entity or a group of entities at the same time.

An action can be performed from the **Data view** or the **Workflows** modules.

## Create Actions

To create an action, follow these steps:

1. Press the **"+"** button
2. Fill in the necessary information
3. Press **"CREATE"**

## Create Operation

To create an operation within an action, follow these steps:

1. Press the **"+ Create"** button
2. Fill in the necessary information (Name, Operation type)
3. Press **"CREATE"**

There are 4 types of operations that can be created:

- Create an entity using the form
- Update entity using the form
- Delete entity using the form
- Assign entity to projects

One action can group a series of operations.

## Edit / Delete Action

Any action can be edited or deleted.

> **Note:** Actions cannot be deleted if they are being used by other modules (e.g., Workflows).
